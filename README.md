# Wordclock community themes

Catalogue for Wordclock 3.0. The version 1 index is `catalog.json`; individual themes use version 2. Each index entry points to a relative JSON path.

Community theme contributions are accepted under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/), subject to manual review. See [CONTRIBUTING.md](CONTRIBUTING.md). This licence statement concerns themes, not the firmware or website code.
