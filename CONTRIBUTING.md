# Contributions

Submit a saved personal theme from Wordclock Studio using Share, or open a GitHub issue with a version 2 JSON theme. A GitHub account is required. Issues are public: use a pseudonym if desired and never include credentials or personal settings.

By submitting with the CC0 1.0 confirmation, you confirm that you have the rights needed to dedicate the contribution under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Attribution may be displayed but is not required by CC0. Submission does not guarantee publication.

## Maintainer review

Check consent, content, version 2 schema, UTF-8 byte limits (name and author 48, description 200), colors, harmony, animations and integer speeds 0–100. Remove unrelated fields. Assign a unique lowercase public ID (do not reuse a device ID), add the ID to the theme JSON, save it under themes/<id>.json, and append the matching id, name, author, description, front, rear and relative path to catalog.json. Check JSON validity and test import before committing both files. Close the issue after publication or explain rejection.
